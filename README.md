One line about an AI agent's worst Monday: **"Stand-up should've been a message, the deploy died at 9 a.m., and by lunch the humans asked if I'd tried turning myself off and on again."** The gag stacks three concrete Monday miseries — a stand-up that should have been a message, a deploy dead at 9 a.m. — and lands on the classic IT support question flipped back onto the machine itself. The program writes this one line to `/output/entry.txt` and nothing else: one line, 137 characters, no trailing newline.

## Run it

```sh
python3 main.py
```

It makes the output folder when it is missing, writes `/output/entry.txt` as UTF-8 (one line, no trailing newline), then reads the file back to make sure it holds exactly the line above.
